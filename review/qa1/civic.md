# QA round 1: the round's themes applied to the civic room types (Q1A)

The user rated only part of the room types in QA round 1 (armoury .. great hall) and asked that the round's high-level
feedback and recurring themes be applied to the types they did not rate. This ledger covers the civic types: dining
hall (dining_hall, mess_hall, ogre_hall), gallery, hall, kitchen, living room (living_room, dwelling), solar, study,
library, tavern, throne room, shop, infirmary, herbalist. The user's two themes, closing the round:

> "Much of the feedback boiled down to" (1) the rooms are too empty, with not enough object diversity, and (2) there is
> no balance or symmetry: things are placed randomly, not lined up with each other.

The rows quote the theme statement or the rated room's note each lesson came from (`review/reviews/QA-round1.md`).
How it is done: `mapgen/kit/civic.py` composes these kinds whole (Furnisher.compose's `civic` slot, then `civic.finish`
in place of the generic fill, density, lining, lighting and grammar passes, whose random top-ups and Westwood-statistics
moves had undone the balance asked for); the type rules are in each `rules/rooms/<type>.md`, section "QA round 1".
